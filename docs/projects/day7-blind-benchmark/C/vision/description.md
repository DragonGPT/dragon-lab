竖幅全身人物立绘，一位纤细的少女居中站立，身体略微倾斜，双臂自然向两侧舒展，手指轻轻张开，双腿并拢交错，一只脚稍向前。她面向观众，头微微歪斜，紫色大眼睛明亮，脸颊泛红，张嘴露出甜美笑容。银白中带淡紫色的长发十分蓬松，刘海分缕垂在额前，头顶有一缕翘发，长长的卷发波浪般铺展至身体两侧和裙后。头上长着一对白色弯曲龙角，角表面有细致鳞片，耳朵尖尖，一侧佩戴白色绳结花饰与垂落的紫色晶石耳坠。

她穿着精致的白色礼服，整体带柔和的薰衣草紫阴影。高领蕾丝连接无袖修身上身，肩部裸露，胸前有细链与淡紫色花纹装饰；双臂套着宽大的分离式喇叭袖，袖口层层荷叶边，缀有花纹和晶石。腰间白色绳结花饰连接垂坠的银色链条，链上悬挂多枚透明淡紫色菱形宝石。裙摆前短后长，露出双腿，宽大的长裙向两侧铺开，由多层波浪褶边组成，表面点缀浅紫色花卉纹样。脚穿白色尖头鞋，脚踝有蕾丝花饰和紫色坠饰。

背后展开一对白色至浅紫色的膜翼，细长翼骨撑起弧形翼膜；画面右侧露出粗大的白色鳞片龙尾。背景为干净的浅灰白色，脚下有柔和阴影。整体是细腻明亮的日式动漫插画风，线条纤细，配色以白色和淡紫色为主。
