# 匿名验收记录

本页区分静态证据与实际运行证据，不作综合能力排名。验收未修改各组原作。

## 已验证

- **交付完整性**：A/B/C各有原始SVG、视觉描述、还原图片、小屋首轮与加赛网页。
- **SVG**：三份均通过XML解析；当前文件未发现DTD/实体声明、脚本、事件属性、嵌入外部内容或非片段资源引用。使用同一既有渲染器按宽1200像素、保持原比例栅格化，已查看结果；无补画或增强。此为静态渲染，不是网页交互测试。
- **还原图片**：三张PNG完整性检查通过，均为1024×1536。此项不评价与参考图的相似度。
- **小屋语法**：六份HTML中的内联脚本均通过JavaScript语法检查；没有执行WebGL，也没有验证依赖加载或交互。
- **匿名检查**：各组原作未检出常见模型名称标记、内部文件位置或身份映射引用；方法页公开候选名单但不对应A/B/C。
- **链接检查**：HTML中静态的相对href/src引用均指向存在的公开素材；这不覆盖脚本动态构造的链接。

## 未验证

六份小屋网页尚未取得真实浏览器视觉与操作验收证据。首屏画面、WebGL启动、环绕、缩放、加赛第一人称移动、手机方向键、模式切换、回起点及移动端布局均不能据静态代码宣称通过。

六份网页均依赖指定的Three.js 0.170.0 CDN，不是完全离线自包含；CDN实际可达性未验。环境阻塞不自动计为模型错误。后续如取得正式发布页面的浏览器证据，应单独更新本节。
