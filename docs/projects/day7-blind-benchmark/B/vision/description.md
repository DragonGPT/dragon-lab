竖幅日系二次元精细插画，浅灰白色纯净背景，中央完整呈现一位白皙少女，脚下只有柔淡的灰紫色投影。少女微微歪头，紫罗兰色大眼睛望向前方，脸颊泛粉，张开小嘴露出明朗笑容。银白偏淡紫的浓密长发从头顶垂落，层层卷曲、向两侧舒展，几乎铺满身体后方，额前有柔软碎刘海，头顶翘起一缕弯曲发丝。头部两侧长着粗大的乳白色弯角，表面覆盖淡粉紫阴影的片状鳞纹，尖端向上弯曲；耳朵细长尖锐。画面右侧耳上别着银白盘结花饰，下垂细链与紫色水晶。身穿白色与极浅薰衣草紫相间的露肩礼服，颈部有蕾丝立领，胸前开出小巧镂空，修身上衣中央排列浅紫花叶纹与交叉细带。两臂套着宽大喇叭袖，袖缘层叠荷叶褶，点缀细致花纹。腰间饰有盘结花形金属扣，多道银色链条斜垂于裙面，悬挂长短不一的透明紫水晶坠。裙摆前短后长，外层不规则展开，内层密集堆叠柔软波浪褶，边缘绘浅紫花卉刺绣。背后展开一对白紫色蝙蝠状膜翼，骨架纤细，翼尖下垂；右后方盘出一条覆盖菱形鳞片的粗长白色尾巴。双臂自然向两侧下方伸展，手指轻轻张开，双腿略微交叠，穿白色尖头高跟鞋，鞋面及脚踝有花形蕾丝、系带和紫晶坠饰。整体线条清秀细腻，色彩明亮低饱和，柔光与透明感阴影营造轻盈梦幻质感。
