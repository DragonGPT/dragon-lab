# Day 7 三模型匿名同题体验

候选为 GPT-6.1 Terra、GPT-6.1 Sol、GPT-6 Astra；名单顺序不对应 A/B/C。三者均显式指定 high，使用同一协作任务环境，各关新上下文。当前每关每模型仅一次样本，不是综合能力排名。

## 第一关
用户提示词原文：

Generate an SVG of a pelican riding a bicycle

保留原始 SVG，不修改比例、结构或内容。共同环境具备文件及渲染工具，各模型自行使用工具，因此这是智能体环境中的原题体验，不是无工具 API 裸模型基准。预览图只等比栅格化，不增强或补画。

## 第二关
所有选手看到同一张 1024×1536 角色参考图。提示要求中文 400–600 汉字描述，仅依据该图，不查其他资料。完整描述保存在各组 vision/description.md。原描述逐字交给同一内置图片生成工具，各一张，无参考图片、无其他图片上下文参数、不润色、不挑选、不返工。输出均为 1024×1536 PNG。精确生图后端版本与 seed 未由工具公开，不作声明。

这测的是视觉描述与统一文字生图的组合链路，不是三个模型各自的原生生图能力。生图随机性未被排除。

## 第三关
同一小屋任务提示，各一轮生成，允许该轮内部自主工具检查，不给人工改稿。首轮明确无移动控制，允许环绕观察和缩放。所有选手均使用指定 three@0.170.0 CDN，程序化几何，无外部图片模型。原始工程和其他选手结果未作为输入。

加赛向每位发送相同的一轮追加要求，增加第一人称移动、手机方向键、模式切换和回起点。各自在自己的首轮成果基础上修改，首轮另存保留。因此加赛反映从生成到修改的端到端体验，不是同一代码起点的独立修 bug 能力对照。
