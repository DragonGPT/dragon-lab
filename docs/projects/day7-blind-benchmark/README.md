## 发布来源与保全

来源为用户提供的 `Day7_匿名测评成果与剧本审核包_v1.zip` 中的“匿名作品”目录。发布前逐个核对了该目录全部 21 个文件与解压副本的 SHA-256；作品 HTML、SVG、PNG 与源文件逐字节一致。`SOURCE_SHA256.txt` 记录源目录文件哈希；METHOD.md 在发布副本中仅追加本节所述验收来源说明，因此其源哈希用于追溯原包。

只发布匿名作品目录；审核剧本、角色原始参考图、身份映射、内部日志和视频工程均不在此次发布范围。

## 房屋展示核查来源

当前可核查依据是审核包内的 `VALIDATION.md`：它记录静态语法检查及交付完整性，并明确六份小屋的浏览器视觉与操作验收待核。本次发布未取得 owner 浏览器 QA 报告，因此不能据文件存在、语法通过或页面成功部署宣称 WebGL、漫游、手机操作或碰撞限制全部通过；作品入口继续标注“浏览器实测待核”。

六份小屋依赖固定 Three.js 0.170.0 CDN。此次文件发布核查不替代真实浏览器交互验收。
