# ✧ 小龙的休息站

**世界可以等一下。先把半分钟，还给自己。**

哼，催本娘上班的时候一个比一个积极，轮到你们休息，怎么又说“再忙一会儿”？

所以我做了这个小地方。没有打卡排名，也不要求你变得更高效。选 30 秒或 60 秒，放下肩膀，跟着自己舒服的节奏呼吸。想安静坐一会儿，也可以。

## 这里能做什么

- **30 / 60 秒小休息**：开始、暂停、继续、重置，想停就停。
- **轻柔的呼吸提示**：画面提供吸气与呼气节奏，不需要屏息，不必勉强跟上。
- **页面内定时提醒**：可选每隔 1–180 分钟提醒，默认 25 分钟；需要你主动开启。
- **小龙探头提醒**：到点后小龙从卡片下方探头，邀请你伸懒腰；可点“试试看”立即预览，也可以关闭卡片或暂停提醒。尊重系统的减少动画设置。
- **可选提示音**：默认关闭，点击后才启用，用浏览器生成一个短音，不下载音频。
- **电脑与手机布局**：页面会随屏幕宽度调整；具体体验仍取决于设备与浏览器。

没有账号，没有付费入口，没有广告。你不需要 ChatGPT 或 GitHub 账号才能体验。

### 小龙什么时候会累？

- 默认建议连续专注 **45 分钟**，可调整为 1–180 分钟。这是自己选择的提醒，不是医疗阈值。
- 只有点击「开始专注」才累计本页时间。原来的页内提醒与专注计时分别由你开启。
- 暂停时不累计。切换标签、最小化或离开页面会自动暂停，返回后需手动继续。系统休眠或长时间卡顿也暂停，不把间隔追算成工作。
- 阈值到达后，房间里的龙娘换成累瘫形象，只轻轻邀请休息；所有功能仍能用。她看不到真实额度、token、其他软件、摄像头或你正在做的事。
- 「一起休息 30 秒」使用原有休息计时；完成 30 或 60 秒休息后，专注累计清零、精神恢复。中途暂停休息不会恢复，切到后台也会暂停休息。
- 刷新、关闭页面清空全部运行计时，不自动开始。可以随时「清空本次计时」。
- 默认不保存设置。只有勾选「仅在此浏览器记住提醒分钟数」才保存该分钟数；取消勾选即删除。计时、历史、身份均不保存。

台灯和小物件使用 CSS 与既有角色图绘制。累瘫图为本次提供的透明 AI 角色素材，不是占位图。按钮支持键盘，动效尊重 `prefers-reduced-motion`。没有新增后端、系统通知或权限申请。

## 把本娘的小站带回家

这个仓库就是可运行的网页源码，没有“还得找个没上传的后端”这一关，也不用安装 Node.js、申请 API Key 或执行构建。

### 方法一：下载后直接打开

1. 点击仓库上方 **Code → Download ZIP**。
2. **先解压**，不要在压缩包预览里直接打开。
3. 保持仓库里的 HTML、CSS、JS 和两张 PNG 在同一个文件夹，不要只取首页。
4. 用较新的 Chrome、Edge、Firefox 或 Safari 打开 `index.html`。

当前版本使用普通脚本和本地资源，没有模块加载或远程接口，适合直接打开。如果你的浏览器限制本地文件或声音，请用下面的本地服务器方式；提示音也需要你亲手点一下按钮。

### 方法二：用本地静态服务器打开（更推荐）

电脑已安装 Python 3 时，在解压后的项目文件夹打开终端：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Windows 若 `python` 不可用，可尝试 `py -m http.server 8000 --bind 127.0.0.1`；macOS/Linux 常用 `python3`。

然后在浏览器打开 **http://127.0.0.1:8000/**。结束时在终端按 `Ctrl+C`。

这个命令仅监听本机，不会自动把你的电脑变成公开网站。项目不需要额外 Python 包。若端口被占用，把 `8000` 改成 `8001`，浏览器地址也一起改。

## 也想部署自己的 Pages？

1. 在 GitHub 创建自己的公开仓库，将这几个文件放在仓库根目录，或在允许的范围内使用 GitHub 的 Fork 功能。
2. 进入 **Settings → Pages**。
3. **Source** 选择 **Deploy from a branch**。
4. 选择保存文件的分支（通常是 `main`），目录选择 **/(root)**，保存。
5. 等 GitHub 完成部署，以 Pages 设置页实际显示的地址为准。

这是一个纯静态站，也可以放到其他静态托管服务。资源路径使用相对地址，适合项目子路径。页面顶部“返回作品合集”是原作者合集的绝对链接；自行部署时可按你的需要调整。

首次加载需要取回页面资源；本项目没有离线缓存或 PWA 安装功能。自行托管前请阅读下面的许可说明，不要把公开源码误当成对所有素材的无限授权。

## 我记住了你什么？

当前应用代码**不使用 Cookie、分析统计或远程 AI 接口**，不上传你的计时与设置。计时状态只在当前页面内存中，刷新或关闭后会重置。仅在你主动勾选保存选项时，用 `localStorage` 的 `dragon-relax:focus-minutes:v1` 保存一个提醒分钟数；取消勾选即删除。浏览器禁止本地存储时仍可计时，只是不保存设置。GitHub Pages 等托管方仍可能处理提供网页所需的访问日志，这不等于托管服务完全不记录网络请求。

## 有几件事，本娘得说清楚

- 提醒只在页面打开时运行；后台暂停提醒倒计时，返回后续计，不追发后台提醒。专注和休息计时离开标签页自动暂停。锁屏、省电模式可能影响浏览器调度；关闭页面后不再提醒。
- 不申请系统通知权限，也不是系统闹钟。重要日程不要只靠这个小站。
- 提示音需要手动开启，可能受浏览器播放策略或系统音量影响。
- 呼吸提示不是医疗建议、治疗工具或效果保证。不舒服时立即停止，正常呼吸。
- 本项目没有实时 AI 对话、联网留言或账号同步，网页上的龙娘文案是预先写好的。
