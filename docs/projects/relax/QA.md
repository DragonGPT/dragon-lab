# 住客添置第一弹验证

2026-10-23，在独立 Edge 浏览器（关闭 GPU）验证。页面仍为无构建纯静态站。

- 七项：暖灯开关、笔记本开合、镜子表情、龙娘印花油纸伞、坐下与尾巴软垫、独立青色半透明伞及收起、专注疲劳透明角色图均通过。
- 计时：默认 45 分钟模型在 2699 秒未触发、2700 秒触发；浏览器中把阈值调为 1 分钟并使用受控时钟触发实际 UI，无需等 45 分钟。
- 暂停停止累计；浏览器中派发隐藏/可见事件核验切标签处理，回来保持暂停；长调度间隔暂停而不追算。
- 休息中途暂停不恢复；完成 30 秒恢复；原休息计时切后台暂停；刷新计时清空且不自动开始。
- 设置默认不存；主动保存分钟数可保留；取消后删除；刷新恢复默认 45。非法阈值不能开始。
- 1280、768、390、320px 实际浏览器截图已查看；无横向溢出。
- 键盘 Enter 打开房间，控件使用原生按钮与可见焦点；尊重减少动画设置。
- 无页面脚本错误；运行过程只请求同源 HTML/CSS/JS/PNG，无外部接口、摄像头或通知申请。
- 既有休息按钮、探头提醒预览、返回合集链接保留。

计时模型可复验：`node --test tests/timer.test.cjs`。该命令仅用于开发验证，运行网站无需 Node 或安装依赖。
